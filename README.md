### 🧑‍💻 About Me

I'm a **B.Tech student at LPU** who took the *hard*ware path — while everyone else chases full-stack frameworks, I chase **setup time violations**.

```yaml
Domain      : VLSI Design & Verification
Languages   : Verilog · SystemVerilog · VHDL · C · C++ · Java
Protocols   : AMBA AHB · AMBA APB · SPI · I2C · UART
Toolchain   : Xilinx Vivado · Cadence Virtuoso · Spring Boot · MySQL
Currently   : Building UVM testbenches that catch bugs before tape-out
Fun fact    : I've written more testbenches than test cases — and I'm proud of it
```

### 🔨 What I Build

<table>
<tr>
<td width="50%" valign="top">

**⚙️ RTL Design**
100+ digital circuits in Verilog — adders, FIR filters, alarm clocks, FSMs. If it has flip-flops, it's probably in a repo below.

**🔍 IP Verification**
Constrained-random stimulus, functional coverage, scoreboards — the full UVM stack. Verified APB-based controllers and dual-port RAMs end-to-end.

**🌉 Protocol Design**
Built an AHB-to-APB bridge from scratch, because protocols don't bridge themselves.

</td>
<td width="50%" valign="top">

**🔬 CMOS Circuits**
A Mealy machine sequence detector in 90nm CMOS and a VCO-based ADC, simulated entirely in Cadence Virtuoso.

**🎛️ FPGA**
An audio equalizer implemented in VHDL on FPGA — proof that hardware can groove too.

**💻 Software**
When I need a break from waveforms, I build full-stack apps in Java + Spring Boot. Versatility isn't a weakness.

</td>
</tr>
